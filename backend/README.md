# Screen Guide AI Backend

This backend adds an AI fallback layer for the Screen Guide app. It works as a small service that can answer open-ended questions when the local guide database does not contain a match.

## Features

- FastAPI REST API
- Local fallback matching for known guide topics
- Optional OpenAI-backed answer generation for broader questions
- Easy mobile-app integration via a single `POST /api/answer` route

## Setup

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Add your API key to `.env`:

```env
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4o-mini
```

Then start the service:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## API

### POST /api/answer

Request body:

```json
{
  "question": "How do I upload content on YouTube?"
}
```

Response:

```json
{
  "question": "How do I upload content on YouTube?",
  "answer": "To upload a video to YouTube...",
  "source": "llm"
}
```

Possible `source` values:

- `local-match`: answer came from the local guide list
- `llm`: answer was generated by the AI model
- `not-configured`: model was not configured, so the endpoint returned a helpful fallback

## Why this helps

The original Screen Guide app appears to answer only from a static knowledge base. This service fills the gap by adding an AI layer, so it can support broader help questions without requiring every possible topic to be prewritten in the app.
